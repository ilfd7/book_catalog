# Регламент технического обслуживания
## веб-приложения «Каталог домашней библиотеки»

## 1. Общие положения

Настоящий регламент определяет порядок технического обслуживания веб-приложения «Каталог домашней библиотеки», разработанного на языке Python (фреймворк Flask) с использованием базы данных SQLite.

Цель регламента — обеспечить стабильную работу приложения, сохранность данных и своевременное выявление неисправностей.

## 3. Порядок создания резервной копии

1. Остановить приложение (если оно запущено в режиме разработки).
2. Выполнить команду: `python backup.py create`.
3. Убедиться, что в папке `data/backups` появился файл `backup_<дата_время>.zip`.
4. Проверить размер архива — он должен быть больше 0 КБ.
5. Запустить приложение обратно.

## 4. Порядок действий при сбое

### 4.1. Приложение не запускается

1. Проверить наличие файла базы данных `instance/book_catalog.db`.
2. Если файл отсутствует или повреждён — восстановить из последней резервной копии:
   ```
   python backup.py restore
   ```
3. Проверить целостность восстановленной базы данных.
4. Запустить приложение и убедиться в его работоспособности.

### 4.2. Ошибка 500 при добавлении/редактировании книги

1. Проверить права доступа к папке `instance/` (должны быть права на запись).
2. Проверить заполнение обязательных полей формы.
3. Просмотреть логи приложения в консоли.
4. При необходимости — откатить последние изменения через Git:
   ```
   git log --oneline
   git revert <commit_hash>
   ```

### 4.3. Потеря данных

1. Остановить приложение.
2. Найти последнюю рабочую резервную копию в папке `data/backups`.
3. Выполнить восстановление:
   ```
   python backup.py restore --archive data/backups/backup_YYYYMMDD_HHMMSS.zip
   ```
4. Проверить целостность данных через веб-интерфейс.
5. Зафиксировать инцидент в журнале обслуживания (раздел 6).

## 5. Порядок обновления версии приложения

1. Сделать резервную копию базы данных.
2. Получить актуальную версию кода из репозитория:
   ```
   git pull origin main
   ```
3. Установить обновлённые зависимости:
   ```
   pip install -r requirements.txt
   ```
4. При изменении структуры базы данных — применить миграции (если используется Flask-Migrate):
   ```
   flask db upgrade
   ```
5. Запустить тесты и убедиться в их успешном выполнении:
   ```
   python -m unittest discover -s tests -t . -v
   ```
6. Запустить приложение и проверить основные функции.

## 7. Типовые неисправности и методы их устранения

| Неисправность | Возможная причина | Метод устранения |
|---------------|-------------------|------------------|
| Приложение не запускается | Отсутствует файл БД | Восстановить из резервной копии |
| Ошибка 500 при добавлении книги | Нет прав на запись в `instance/` | Проверить права доступа к папке |
| Ошибка 404 при переходе к книге | Книга удалена или неверный URL | Проверить наличие книги в БД |
| Медленная работа приложения | Большая база данных без индексов | Добавить индексы на поля `genre`, `author`; включить пагинацию |
| Резервная копия не создаётся | Нет папки `data/backups` | Создать папку вручную или проверить путь в `backup.py` |
| Несовпадение хеша при восстановлении | Архив повреждён | Использовать предыдущую резервную копию |
