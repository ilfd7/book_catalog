# Home Library Catalog

A web application for managing a home library book collection. Developed in Python (Flask) with a SQLite database.

## Features

- 📚 Browse book collection
- ➕ Add new books
- ✏️ Edit and delete records
- 🔍 Search by title and author
- 🏷️ Filter by genre
- 💾 Database backup and restore

## Installation

Requires Python 3.9 or later.

```bash
# Clone the repository
git clone https://github.com/ilfd9/book_catalog.git
cd book_catalog

# Create a virtual environment
python -m venv .venv
.venv\Scripts\activate   # Windows
source .venv/bin/activate  # Linux/Mac

# Install dependencies
pip install -r requirements.txt
